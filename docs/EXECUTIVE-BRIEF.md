# YKT AI 能力平台 · 方案汇报（领导版）

> 2026-08-24 · 一页纸摘要

---

## 一、我们做了什么

建成公司统一的 **AI 能力平台（ykt-aisaas）**：一套系统同时服务**内部小智设备**和**外部客户**，把大模型对话、语音合成、语音识别、知识库问答、工具调用五大 AI 能力变成标准化的“水电煤”——客户领一把钥匙（API Key）就能用，按用量自动计费。

**当前状态：核心功能全部开发完成并验证通过，随时可接入真实业务。**

---

## 二、解决什么问题

| 之前 | 现在 |
|---|---|
| 每个系统各自接 AI 厂商，重复开发、重复运维 | 一个平台统一接，其他系统“换一行配置”接入 |
| 换 AI 供应商 = 改代码 + 重新测试 | 管理后台改一条记录，**业务零改动**（已验证 OpenAI/国产/自建三种上游通吃） |
| 无用量统计，AI 花费是笔糊涂账 | 每次调用自动计量、按价扣费、生成流水（精确到分） |
| 无法对外提供 AI 服务收费 | 完整 SaaS 商业化能力：租户/套餐/配额/余额/充值 |
| 多家客户共用系统，数据可能互看 | 金融级隔离：**A 客户永远看不到 B 客户一个字节**（专项测试验证） |

---

## 三、核心成果（均已实测验证）

| 成果 | 说明 |
|---|---|
| **五大 AI 能力上线** | 智能对话（打字机式流式输出）、语音合成、语音识别、知识库问答（带出处引用）、工具调用（AI 自动查天气/物流等） |
| **多租户 + 计费闭环** | 充值 → 调用 → 自动扣费 → 查账单，全程自动化；超额自动停止服务 |
| **一套代码两种客户** | 对内服务小智设备（零成本切换），对外卖给客户（按量收费） |
| **极轻的运维负担** | 一台服务器全装下（Go 技术栈：程序仅 30MB、内存 200MB，是同类 Java 方案的 1/10）；中大型客户可私有化部署 |
| **小智设备全面受益** | 切换后即可用上平台的全部新能力（声音克隆、专属模型训练等），不再需要单独开发 |

## 五、商业价值

1. **成本中心 → 利润中心**：AI 能力从“内部消耗”变成可对外销售的标准化产品
2. **议价能力**：平台聚合多家租户的用量向上游（DeepSeek/阿里等）谈量价，单价可降 30%+
3. **锁定客户**：知识库、定制音色、微调模型沉淀在平台，客户粘性持续增强
4. **卡位生态**：MCP 工具市场开放后，形成“客户—平台—工具开发者”三方生态
